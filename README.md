This project converts binary numbers 1-9 into its corresponding number on the seven segment display. 

The following boolean expressions were used in the making of the seven segment display:

Y1: A + BC' + BD'

Y2: A + B'C + BC' + CD'

Y3: AD' + CD' 

Y4: A + B'C + BC'D + CD'

Y5: A + B + D

Y6: A + B'C + B'D + CD + BC'D'

Y7: A + C + BD

Each of the 7 Y values represents the seven outputs used to light up the corresponding region of the seven segment display. The letters A, B, C, and D represents the binary number inputs.

The link to the Circuit Verse page in which the project was created can be found here: https://circuitverse.org/users/476627/projects/seven-segment-binary-display
